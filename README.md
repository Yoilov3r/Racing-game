# Q版氮气竞速 2.8

原生 Windows 3D 赛车游戏，使用 Godot 4.7.2 Forward+ 制作。游戏不依赖浏览器，双击
`Q版氮气竞速.exe` 即可运行。

## 操作

- `W`：加速
- `S`：制动 / 倒车
- `A` / `D`：左右转向
- `←` / `→`：备用左右转向
- `Space`：漂移
- `Shift`：氮气达到 10% 后立即喷射
- `R`：使用当前赛道和 AI 难度重新发车
- `Esc`：暂停 / 继续
- `Q` / `E`：在选图界面降低或提高 AI 难度

## 比赛规则

与 5 名 AI 车手进行多圈竞速。AI 提供新手、标准、高手和大师四档难度。高速巡航会持续补充氮气，转向和漂移会提高充能
速度；氮气槽达到 10% 后可以按 `Shift` 释放。离开赛道会显著降低抓地力和最高速度。
车辆正常极速约 137 km/h，氮气约 194 km/h。空格漂移会平滑降低后轴抓地，
松开或反打后抓地会更快恢复，侧滑角受控，不会持续自旋。

## 赛道

- `1` 霓虹夜街：约 1.30 公里，12.4 米窄路，雨夜湿沥青、连续霓虹街谷、
  远景灯塔与高架捷径构成近距离技术赛道。
- `2` 雪山竞速：约 2.60 公里，14.3 米混合路面，连续路基与桥墩承接长坡，
  落地索道、雪场站房、观众平台和三层山体建立清晰纵深。
- `3` 环城极速：约 3.77 公里，16.8 米宽体高速路，内圈街区、五种地标轮廓、
  看台和城市观景塔形成开阔高速走廊。

开赛前按数字键切换地图，按 `Q` / `E` 调整 AI 难度，按 `Enter` 发车。比赛结束后按
`R` 重赛，按 `T` 返回选图界面。
每张地图都有护栏开口和独立捷径支线，捷径道路较窄且会限制最高速度。
右上角实时小地图显示主路线、橙色捷径、玩家朝向、AI 位置和当前圈数。HUD 使用
自绘速度弧、离散氮气槽和漂移角反馈；高速与氮气状态下仍保留清晰的名次、圈数和
计时信息。

音频按发动机低频 / 中频 / 高频、轮胎摩擦、漂移、氮气、碰撞、倒计时和 UI 点击
分层处理。选图与展厅完全静音，发车后启动比赛音频；进入暂停、结果或展厅时采用
指数淡出，停止阈值低于可闻范围，避免硬切造成爆音。

## 技术

- 引擎：Godot 4.7.2，MIT License
- 渲染：Forward+、MSAA、屏幕空间环境光遮蔽、屏幕空间反射、体积雾和泛光
- 车辆：程序化敞篷赛车，包含连续的曲面车鼻与后肩、分层前后包围、曲面轮拱、
  开放式座舱、方向盘与车手、双片尾翼、扩散器、双排气、制动盘、卡钳、
  多辐锻造轮圈、主动灯组、漂移烟雾和轻微动态悬挂
- 主车身采用十三段连续截面放样，车头、腰线与尾部由同一曲面过渡；车漆、碳纤维、
  玻璃、轮胎、锻造金属、制动件和发光灯罩使用独立 PBR 材质层
- 氮气尾焰由双排气的外层橙焰与内层青焰组成，刹车时尾灯亮度由驾驶状态动态控制
- 选图菜单使用独立 3D 展厅，包含高反射圆形地台、发光边环、蜂窝几何墙与冷暖灯组
- AI：五类性格车手（稳健、激进、漂移、失误、机会型），共享玩家车辆物理和灯光，
  具备闭合竞速线、弯前制动、出弯加速、动态走线、超车、防守、起跑反应、
  碰撞避让和失误恢复；提供新手、标准、高手、大师四档难度，橡皮筋仅调整
  目标速度且限制在 ±6%，不会瞬移或绕过碰撞
- 驾驶：集中配置的引擎、制动、转向、漂移、越野、碰撞、镜头与特效参数，
  包含非线性加速、速度相关转向、漂移进入/退出、侧滑上限、离路软限速、
  速度 FOV、加速拉伸、车身侧倾、碰撞震动、漂移烟和最多 900 段轮胎印
- 赛道：三条独立闭合赛道，分别包含霓虹建筑、雪山针叶林与环城看台设施
- 性能：每条赛道具有独立远裁剪、阴影距离和灯光预算；道路标线、反射器和路面
  细节使用 MultiMesh，减少重复绘制调用
- 环境：霓虹街使用屋檐、设备箱、管线、店门和发光招牌形成近景层次；雪山索道
  沿赛道同侧连续架设；环城天际线包含办公塔、退台塔、双塔、圆塔和阶梯建筑
- 捷径：高架支线拥有独立路面、护栏、桥墩和高度变化，不与主路表面穿插
- 捷径驾驶：不锁定方向、不横向吸附；车辆必须由玩家主动驶入，系统只识别真实支线
  路面并平滑跟随该路面高度；驾驶输入仍只由玩家按键决定
- 外接道路：捷径沿赛道中心的外向方向扩展，和全部主线路段自动保持至少 18 米净空
- 氮气：高速巡航、转向和漂移共同充能，释放后可立即提高极速与加速度
- 音频：五条独立总线、七层比赛循环、程序化轮胎 / 漂移 / 氮气 / 倒计时 / UI 音色，
  所有状态切换均使用无硬切淡入淡出
- HUD：自绘速度弧、分段氮气槽、漂移角仪表、倒计时灯组、透明小地图，适配
  `1280x800` 与 `1920x1080`

## 从源码运行

使用 Godot 4.7.2 打开本目录并运行 `main.tscn`，或在终端执行：

```powershell
godot --path .
```

## 集成检查

五个设计部分的职责、接口与整体更新门禁见 `INTEGRATION.md`。合并后运行：

```powershell
godot --headless --path . --script "res://integration_check.gd"
```

完整整合门禁：

```powershell
.\run_integration_gate.ps1
```

驾驶回归单独运行：

```powershell
godot --headless --path . --script "res://driving_audit.gd"
```

逐项结果写入 `DRIVING_AUDIT.md`。

## 赛道质量验收

运行以下命令重新生成三条赛道的弯道、捷径入口截图、性能数据和净空报告：

```powershell
godot --path . --script "res://quality_audit.gd" --resolution 1280x800
```

- 前后对比：`qa/comparison_neon.png`、`qa/comparison_snow.png`、`qa/comparison_loop.png`
- 捷径入口总览：`qa/entrances_overview.png`
- 细节验证：`qa/detail_<track>_turn.png`、`qa/detail_<track>_shortcut.png`
- 性能与净空：`qa/quality_report.txt`
