# Q版氮气竞速 2.6

原生 Windows 3D 赛车游戏，使用 Godot 4.7.2 Forward+ 制作。游戏不依赖浏览器，双击
`Q版氮气竞速.exe` 即可运行。

## 操作

- `W`：加速
- `S`：制动 / 倒车
- `A` / `D`：左右转向
- `←` / `→`：备用左右转向
- `Space`：漂移
- `Shift`：氮气达到 10% 后立即喷射
- `R`：重新开始
- `Esc`：暂停 / 继续

## 比赛规则

与 5 名 AI 车手进行多圈竞速。高速巡航会持续补充氮气，转向和漂移会提高充能
速度；氮气槽达到 10% 后可以按 `Shift` 释放。离开赛道会显著降低抓地力和最高速度。
车辆正常极速约 120 km/h，氮气会提高极速与加速度。空格漂移提供更大的转向
扭转角，但侧滑幅度仍受控。

## 赛道

- `1` 霓虹夜街：约 1.30 公里，12.4 米窄路，连续技术弯与城市巷道路线。
- `2` 雪山竞速：约 2.60 公里，14.3 米混合路面，高差长坡与低速度发卡弯。
- `3` 环城极速：约 3.77 公里，16.8 米宽体高速路，大半径长弯和两段捷径。

开赛前按数字键切换地图，按 `Enter` 发车。比赛结束后按 `T` 返回选图界面。
每张地图都有护栏开口和独立捷径支线，捷径道路较窄且会限制最高速度。
右上角实时小地图显示主路线、橙色捷径、玩家朝向、AI 位置和当前圈数。
选图与展厅阶段完全关闭发动机和氛围轰鸣，仅在发车就位后播放赛车音频。

## 技术

- 引擎：Godot 4.7.2，MIT License
- 渲染：Forward+、MSAA、屏幕空间环境光遮蔽、屏幕空间反射、体积雾和泛光
- 车辆：程序化敞篷赛车，包含流线车体、清漆车漆、开放式座舱、悬挂、制动盘、
  卡钳、尾翼、扩散器、主动灯光、漂移烟雾和完整驾驶员模型
- 主车身采用九段连续截面放样，车头、轮拱、腰线与尾部由同一曲面过渡；透明座舱
  罩保留驾驶员可见性，并加入银色赛车条纹
- 选图菜单使用独立 3D 展厅，包含高反射圆形地台、发光边环、蜂窝几何墙与冷暖灯组
- AI：闭合样条路线、弯道速度控制、动态走线、圈数、名次和车体接触
- 赛道：三条独立闭合赛道，分别包含霓虹建筑、雪山针叶林与环城看台设施
- 捷径：高架支线拥有独立路面、护栏、桥墩和高度变化，不与主路表面穿插
- 捷径驾驶：不锁定方向、不横向吸附；车辆必须由玩家主动驶入，系统只识别真实支线
  路面并平滑跟随该路面高度
- 外接道路：捷径沿赛道中心的外向方向扩展，和全部主线路段自动保持至少 18 米净空
- 氮气：高速巡航、转向和漂移共同充能，释放后可立即提高极速与加速度
- 音频：发车后播放真实发动机循环，速度与氮气会改变音高和音量；展厅、选图和完赛界面静音

## 从源码运行

使用 Godot 4.7.2 打开本目录并运行 `main.tscn`，或在终端执行：

```powershell
godot --path .
```

## 安装

导出后的 `Q版氮气竞速.exe` 是独立 Windows x64 程序，不需要安装 Godot。
